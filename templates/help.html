Help us

Vayum is a student project and it improves fastest with real feedback from people who live in the cities it covers.

Report a wrong reading

If a value looks far off for your area, note the city, the pollutant and the time you saw it, and send it across. Local readings vary a lot between neighbourhoods, and those gaps are worth mapping.

Add a city

The location list lives in data/locations.json. Tell us which city is missing and which state it belongs to, and it goes in the next update.

Contribute data or code

  • Historical pollutant datasets for Indian cities
  • Better feature ideas for the 24-hour forecast model
  • Accessibility and mobile layout fixes

Reduce what you add to the air

Share rides on high-AQI days, avoid burning waste and garden leaves, keep vehicles serviced, and check the forecast before planning outdoor exercise. Small local choices move these numbers.

Get in touch

Write to hello@vayum.in with the subject line of the section above that fits.
